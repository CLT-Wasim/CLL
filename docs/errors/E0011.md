# E0011 — Compile-time evaluation failed

**Rule:** R-EXP-090
**Phase:** compile-time evaluation
**Severity:** error

## Meaning

The compiler could not produce a valid value for a `comptime` expression. This occurs when the expression depends on runtime-only data or when evaluation exceeds the per-evaluation fuel budget of 10,000,000 steps.

No executable is emitted after E0011. The compiler should identify the `comptime` expression and include the call/evaluation chain where available.

## Resolution

Move work that depends on runtime input outside `comptime`. If the expression is constant, reduce the computation or split it into smaller constant evaluations. The fuel limit is a safety bound, not a setting that silently changes program semantics.

## Conformance coverage

`tests/conformance/compiletime/neg_runtime_input.cll` covers runtime-dependent input. A separate fuel-exhaustion test is required when the compile-time evaluator is implemented.
